# Provider research and activation costs

Checked against official pages on 18 September 2026. No accounts were purchased or billed. Local demo operation makes no paid provider calls. Hosting, domain and staff time are separate operating costs.

| Provider | Observed pricing/limits | Implementation and source |
|---|---|---|
| Google Calendar | Standard API use is currently described as no additional cost; Google notes planned charges for exceeding quota request limits later in 2026. Account/Workspace charges may still apply. | OAuth refresh, free/busy and verified event insertion with Meet conference data. [Quota/pricing](https://developers.google.com/workspace/calendar/api/guides/quota), [free/busy](https://developers.google.com/workspace/calendar/api/v3/reference/freebusy/query), [event insertion](https://developers.google.com/workspace/calendar/api/v3/reference/events/insert) |
| Google Sheets | Official limits show 300 read and 300 write requests per minute per project, and 60 per user/project. Standard use is described as no additional cost, with the same later-2026 excess-quota charging caveat. | Private tracker; RAW values and stable IDs. [Limits and pricing](https://developers.google.com/workspace/sheets/api/limits) |
| Resend | Free tier listed at 3,000 emails/month and 100/day. Pro listed at USD 20/month for 50,000/month, with USD 0.90 per additional 1,000. Recheck current billing before activation. | Verified sender domain and idempotent email POST. [Pricing](https://resend.com/pricing), [send API](https://resend.com/docs/api-reference/emails/send-email) |
| WhatsApp Business Platform | Delivered-message pricing varies by recipient market and category. The official page states service replies in the user-opened 24-hour window are free. Utility/authentication volume tiers apply. No single flat fee can be inferred for all four markets. | New business number and approved template required. Direct Meta adapter avoids assuming a BSP contract, but a chosen BSP may add fees. [Official pricing/rate selector](https://business.whatsapp.com/products/platform-pricing), [Meta documentation](https://developers.facebook.com/documentation/business-messaging/whatsapp) |
| OpenAI API, optional | As a bounded low-cost reference, the official GPT-4o mini page lists USD 0.15 input and USD 0.60 output per million text tokens; cached input USD 0.075. This is a reference model, not a claim that it is the latest or that account access is guaranteed. Choose a supported model at activation. | Responses API structured output; maximum 500 output tokens and eight calls per lead. Separate API key/billing required. [Model/pricing](https://developers.openai.com/api/docs/models/gpt-4o-mini), [structured outputs](https://developers.openai.com/api/docs/guides/structured-outputs) |

At the reference model's stated rates, 1,000 input and 500 output tokens would be about USD 0.00045 for text generation alone. Real usage depends on selected model, actual tokens, retries and any extra tools; no monthly total is promised. Set project spend limits and review bills.

Meta's dynamic rate table did not expose a stable complete four-market numeric rate card in the retrieved page. This build therefore records the official pricing source and category rules instead of inventing precise WhatsApp totals. Capture the applicable approved-template rates in the activation budget before sending live messages.

The React and Vite implementation was checked against the official [React build-from-scratch guide](https://react.dev/learn/build-a-react-app-from-scratch) and [Vite guide](https://vite.dev/guide/). Dependencies are pinned in package.json and pnpm-lock.yaml. A target-host dependency/security audit remains part of live activation.
